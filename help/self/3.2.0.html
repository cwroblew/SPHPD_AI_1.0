Section 3.2.0: Excluding Keywords from Keyword Index Cache

You can exclude common words or any words you like from being indexed into the keyword index cache. This will reduce the number of words that are indexed and also increase search performance.


Configuration for excluding keywords

The following configuration in help.conf specifies the name of the file which stores the words to be excluded from the index generation process. 
 define('EXCLUDED_WORD_FILE' , ROOT_PATH     . REL_APP_PATH . '/excluded.words');


You can view this file to see which words are already listed.


Adding new exclude words

To add new words to be excluded from keyword index, edit the excluded.words file and add new words in the file. The file has a very simple format: one word per line.

Once you have addded the new words, you must run the makeindex.php to recreate the index with new words excluded. You can run the makeindex.php as follows: 
 http://yourserver/help/apps/makeindex.php
