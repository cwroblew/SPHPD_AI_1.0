Section 1.0.0: Introduction to Help System

This help system offers the following features.

  • Structured Help Contents. The system will assume a structured help content design where help for an application will be divided into sections. Each section will be represented with one or more HTML pages, which may or may not have embedded images. Each section will have a number like x.y.z where X is the section number, y is the second level sub-section number, and z is the third level sub-section number. For example, 1.0.0.html, 1.1.0.html, 1.1.1.html are pages for section 1. The images for all the help contents will be stored in a images direcotry.

  • Automatic Table of Content Page. The system should generate the table of contents page automatically. This is very good to have since we can add or remove sections

  • Automatic Navigation. The system should generate automatic navigation links from section to section and also have link to the table of contents from each page.

  • Keyword search. The system will allow keyword based search using logic operator AND and OR.

  • Template based Interface. The system should support a central help template to display help pages but also allow inidividual sections to have their own templates to alter look and feel of the help as needed.

 

Help Applcations

  • help.php - responsible for displaying Table of Contents, section pages, and search operations. You are running this application right now!

  • makeindex.php - responsible for creating search keyword index cache. This should be run whenever you update help contents to sync up the index cache with the changes you made to your help contents.

Configuration Files

  • help.conf - the primary configuration file. You will need to customize this file to add applications to use this help system.

  • help.messages - the messages file. You do not need to modify this file unless you want to customize messages displayed by the applications

  • help.errors - the error messages file. You do not need to modify this file unless you want to customze error messages displayed by the applications.

  • excluded.words - the file stores word that are to be excluded from keyword index cache generated by the makeindex.php application.
