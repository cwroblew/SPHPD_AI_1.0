Help on Help: Section 4.0.0

 

Section 4.0.0: Changing Look and Feel

You can customize the look and feel of the help pages by modifying the global templates.


Global Templates

The help.conf file has the following template related configuration: 

define(TEMPLATE_DIR , ROOT_PATH . REL_APP_PATH . '/templates');

define('GLOBAL_DEFAULT_TOC_TEMPLATE_FQPN', TEMPLATE_DIR . '/toc.html');

define('GLOBAL_DEFAULT_SECTION_TEMPLATE_FQPN', TEMPLATE_DIR . '/section.html');

define('GLOBAL_DEFAULT_SEARCH_RESULT_TEMPLATE_FQPN', TEMPLATE_DIR . '/search_result.html');
The TEMPLATE_DIR specifies the template directory path, GLOBAL_DEFAULT_TOC_TEMPLATE_FQPN specifies the default template for showing table of contents, GLOBAL_DEFAULT_SECTION_TEMPLATE_FQPN specifies the template for showing section help, and GLOBAL_DEFAULT_SEARCH_RESULT_TEMPLATE_FQPN specifies the default search results template.
None of these templates are used if your help map specifies their replacements using the following configuration:


Application Help Specific Template Configuration

You can use your own templates for each application use the help system for. The map file for your application can have following configuration parameters: 

$DEFAULT_SECTION_TEMPLATE =  'default_section.html';

$TOC_TEMPLATE = 'toc.html';

$TEMPLATES = array(
                       'section_number' => 'template_name.html',
                       'section_number' => 'template_name.html',

			...

                       'section_number' => 'template_name.html'
                 );

$SEARCH_RESULT_TEMPLATE = 'search_result.html';
The help application first tries to locate application specific templates for table of contents, section help pages, and search results using the above configuration information. If it fails to find a specific template, it uses the global default template.
To create your own template, first copy the appropriate global template and modify the copy. There are embedded HTML comments in the templates that serve as block markers which looks like: 
<!-- BEGIN mainBlock -->

<!-- END mainBlock -->
There are many embedded comment markers in each of the templates so make sure you do not delete or modify them.

Updating Table of Contents Template

By default the help application use the GLOBAL_DEFAULT_TOC_TEMPLATE_FQPN table of contents template which is stored in %DocuemntRoot%/help/templates directory. You can modify this file to change the look and feel of all of your help TOC throughout the system. This will make the change available to all application help.

However, if you want to just change the look and feel of the TOC for a specific application, you should copy the global TOC template into the template directory (specified in map file) of your application help contents and modify it to suit your needs.



Updating Section Contents Template

By default the help application use the GLOBAL_DEFAULT_SECTION_TEMPLATE_FQPN section contents template which is stored in %DocuemntRoot%/help/templates directory. You can modify this file to change the look and feel of all of your help throughout the system. This will make the change available to all application help.

However, if you want to just change the look and feel of the sections for a specific application, you should copy the global sections template into the template directory (specified in map file) of your application help contents and modify it to suit your needs. You need to copy the global default section template to your application's help template directory as named $DEFAULT_SECTION_TEMPLATE as configured in your map file.

On top of that if you need to fine tune look and feel for specific sections within an application, you can use the $TEMPLATES array to define specific templates for specific sections.

Updating Search Results Template

The default search result page is displayed using GLOBAL_DEFAULT_SEARCH_RESULT_TEMPLATE_FQPN template. If you want to customize the search result for your application, copy the GLOBAL_DEFAULT_SEARCH_RESULT_TEMPLATE_FQPN template to your application's help directory as $SEARCH_RESULT_TEMPLATE and modify it to suit your needs.
