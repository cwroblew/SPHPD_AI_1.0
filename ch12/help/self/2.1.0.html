Help on Help: Section 2.1.0

 

Section 2.1.0: Configuring help.conf file

The very first step in making online help available for your application is to configure the help.conf file. Here we will discuss how.

 

Editing help.conf

Load help.conf in your favorite text editor and locate the following lines: 

   // This associative array associates an application with a help map file
   $APP_HELP_MAP = array(
                    'self' => 'self.map'
                   );
Now add your application in the $APP_HELP_MAP. For example, to add an application called IRM you can modify the aboove lines as follows: 

   // This associative array associates an application with a help map file
   $APP_HELP_MAP = array(
                    'self' => 'self.map',
                    'irm' => 'irm.map'
                   );

Note
Notice that irm is added after the self (the help application itself) line and a comma is added to the 'self' => 'self.map' line.

Once you have added your application in $APP_HELP_MAP, save the changes to the help.conf file.
