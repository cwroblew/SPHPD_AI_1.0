Section 2.0.0: Getting Started



In this section we will discuss how you can add help to one of your existing Web applications. Adding help you an existing Web application is quite easy since you only have to add help links in your application. All the help contents are external to your application and therefore requires very little efforts to get help up and running.
Here is the TODO list to get online help feature for your Web application:

  • Adding your application to help.conf file

  • Creating help map file for your application

  • Creating help contents

  • Linking help with your application interface

  • Testing help
