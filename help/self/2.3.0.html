Help on Help: Section 2.3.0

 

Section 2.3.0: Creating Help Contents

Once you have configured help.conf and created a map file in the maps directory you are ready to create contents. You need to create a section file for each section you mentioned in the map file. For example, say, your map file has the following $SECTIONS list: 

 $SECTIONS = array(
                  '1.0.0' => 'Introduction',
                  '2.0.0' => 'Creating Mail Message',
                  '3.0.0' => 'Sending Mail'
                  );
You will have to create 1.0.0.html, 2.0.0.html, and 3.0.0.html files in the help directory specified by the $HELP_DIR variable in your map file.

For example, if your map file has $HELP_DIR set to help/myapp and ROOT_PATH in help.conf set to %DocumentRoot% then you need to create the help contents in %DocumentRoot%/help/myapp directory.


Embedding Image Links

The section contents file you create can have embedded images. However, you must follow the rules below when creating image links inside your section contents files:

Image Links - you should use relative image links when embedding images in section contents.
The supported image link are:

< ... src="images/yourimage.ext" ... >


Or,

<... background="images/yourimage.ext" ... >


The actual tags can be img, td, body, etc. For example:


<img src="images/yourimage.ext" alt="my image" >


Or,

<td background="images/yourimage.ext" >



Embedding Links to Other Sections

The section contents file you create can have embedded links to other sections. However, you must follow the rules below when creating links inside your section contents files:


<a href="section_number.html"> Jump to Section 2.3.0 </a>


Such link will be automatically turned into help links that works.
